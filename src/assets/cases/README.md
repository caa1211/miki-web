# Case gallery images

Add approved case images here. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, and `.avif`.

The `/cases` page discovers this folder at build time, sorts by filename, and automatically generates responsive WebP thumbnails plus an optimized dialog image. Use sortable names such as `2026-01-waxing.jpg`.

Only publish images with explicit client consent. Avoid identifying filenames and sensitive metadata. Cases are documentation, not guaranteed results.
